# 🍽️ Nirvana Restaurant

A responsive restaurant web application designed to showcase culinary menus, facilitate dining reservations, and provide an elegant customer dining experience.

---

## ✨ Features

- **Interactive Food Menu:** Categorized food and beverage listings with pricing, descriptions, and dietary options.
- **Table Reservations:** Online reservation booking interface for dining tables and special events.
- **Responsive Layout:** Optimized display across desktop, tablet, and mobile browsers.
- **Location & Contact:** Operating hours, location details, and direct contact options.

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML5, CSS3, JavaScript
- **Templates:** Jinja2
