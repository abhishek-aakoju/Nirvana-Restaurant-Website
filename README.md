# Nirvana Restaurant Website

A full-stack restaurant management website featuring an online table booking system, contact forms, and a dynamic menu tracking interface.

## 🚀 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python Flask
* **Database:** MongoDB
* **Security:** Werkzeug Hashing, Python-Dotenv
